# VB
Holds a collection of useful classes and code I used using VB5/VB6 at the turn of the century

## ImageManipulation subdirectory

Contains a sample project which shows the use of the following classes

clsSize  - main resizer class

clsAtObj - helper object

clsRemember - separate class which handles save and restore of (standard) control states
